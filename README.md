# Web Profil Pribadi (UI & Struktur PHP)

Prototipe antarmuka (UI) website profil pribadi menggunakan **HTML, CSS, dan struktur dasar PHP**. Proyek ini berfokus pada perancangan tampilan halaman profil utama serta kerangka antarmuka halaman admin.

## Cakupan Proyek
- Perancangan tampilan halaman profil utama (`index.php`)
- Kerangka antarmuka halaman admin dan pembaruan data (`admin.php`, `update.php`)
- Integrasi aset gambar profil (`foto_irvan.jpg`)

## Teknologi
- HTML & CSS
- PHP (Struktur Dasar)
